## 支付和充值异常排查

先确认是否有可用海外支付方式。如果没有，可以使用卡密充值方式，重点核对账号 ID 和套餐。

## FAQ

### Grok Super 官方支付为什么不顺？

可能和支付方式、地区、订阅入口或账号状态有关。国内用户没有稳定海外支付条件时，付款链路更容易卡住。

### Grok Super 国内怎么充值？

先购买充值卡密，再输入卡密验证，获取账号 ID，确认账号信息后提交充值。

### 没有海外信用卡能开通吗？

可以使用支持微信支付的卡密充值方式，把会员开通到自己的 Grok / X 账号。

### SuperGrok 支持微信支付吗？

可以通过 GoPlus 入口购买相关充值卡密，再按页面提示完成账号 ID 和确认充值流程。

### 充值需要账号密码吗？

不需要把账号密码交给别人。优先使用自己登录账号、自己获取账号 ID、自己确认订单的流程。

### 账号 ID 在哪里获取？

登录目标 Grok / X 账号后，访问 `https://grok.com/api/auth/session` 获取。复制前确认当前账号正确。

### 账号 ID 可以填邮箱吗？

不要填邮箱。账号 ID 应从 Grok session 页面或充值页面获取链接中获取。

### 账号 ID 复制错了怎么办？

还没提交时重新获取即可。已经提交后不要重复下单，保留订单号和错误信息联系售后。

### SuperGrok 和 Grok Super 怎么区分？

用户搜索时经常混用，实际套餐名称和权益可能随官方调整。下单前以购买页面和 Grok / X 页面展示为准。

### 充值后没显示怎么办？

先刷新或重新登录。如果长时间没有变化，保留订单号、付款记录和账号 ID，联系售后核对。

### 账号 ID 页面打不开怎么办？

确认已经登录目标账号，再换浏览器或刷新重试。仍无法打开时，可以使用充值页面里的获取链接。

### 充值前最重要的检查是什么？

检查当前登录账号、套餐名称、账号 ID 和确认页信息。账号 ID 是整个流程中最容易出错的部分。

### Grok 适合替代 ChatGPT 或 Claude 吗？

不完全适合。Grok 更偏实时信息和 X 内容，ChatGPT 更偏综合任务，Claude 更偏长文档和复杂资料。

### Grok Super 适合哪些使用场景？

适合实时搜索、X 热点分析、社媒讨论整理、新闻追踪、短内容选题和观点归纳。
