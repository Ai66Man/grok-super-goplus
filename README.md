## FAQ

### Grok 国内可以直接订阅吗？

可以尝试官方订阅，但国内用户可能遇到支付方式、地区和风控限制。没有合适支付方式时，可以使用卡密充值。

### 充值需要账号密码吗？

不建议提供账号密码。优先选择自己登录账号、自己获取账号 ID、自己确认订单的流程。

### 账号 ID 在哪里获取？

登录目标 Grok / X 账号后，访问 `https://grok.com/api/auth/session` 获取。复制前确认当前账号正确。

### SuperGrok 和 Grok Super 怎么区分？

用户搜索时经常混用，具体名称和权益应以购买页面和官方页面显示为准。

### 充值后没显示怎么办？

先刷新或重新登录。如果长时间没有变化，保留订单号、付款记录和账号 ID，联系售后核对。
